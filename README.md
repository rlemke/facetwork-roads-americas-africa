# World low-zoom roads: Americas and Africa

605 interactive road maps built from OpenStreetMap with [Facetwork](https://github.com/rlemke/facetwork) ([fwh_osm_lz](https://github.com/rlemke/fwh_osm_lz)).

Browse: https://rlemke.github.io/facetwork-roads-americas-africa/

This public copy keeps the road tiles (PMTiles) up to zoom 7; the map enlarges them beyond that. Road data (c) OpenStreetMap contributors, ODbL.
